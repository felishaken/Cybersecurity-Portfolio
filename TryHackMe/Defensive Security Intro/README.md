# TryHackMe — Defensive Security Intro

## Overview

This room introduced me to the fundamentals of defensive cybersecurity
and the role of security teams in detecting and responding to suspicious
activity.

## What I Learned

- The difference between offensive and defensive security
- The role of a Security Operations Centre (SOC)
- How security teams monitor suspicious activity
- Basic security alert investigation
- The importance of identifying threats and responding appropriately
- Basic incident response and containment concepts

## Skills & Concepts
