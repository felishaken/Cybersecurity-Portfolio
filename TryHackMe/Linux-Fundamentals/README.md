## Objective

The objective of this lab was to develop a basic understanding
of the Linux operating system and become comfortable working
with the Linux command line.

- Linux filesystem
- Directory navigation
- File and directory management
- Linux commands
- Users and groups
- File permissions
- Processes

## Tools / Environment

- Linux
- Bash Terminal
- TryHackMe
